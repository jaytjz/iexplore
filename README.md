# AI Image Detector - Promotional Website Structure

## Project Overview
A promotional website for the "Demystifying ML" module project focused on detecting AI-generated images.

## Directory Structure

```
ai-image-detector-promo/
├── index.html              # Main landing page
├── css/
│   └── style.css          # Main stylesheet
├── js/
│   ├── main.js            # Main JavaScript functionality
│   └── animations.js      # Scroll animations and interactions
├── images/
│   ├── logo.png           # Project/team logo
│   ├── hero-bg.jpg        # Hero section background
│   ├── demo-samples/      # Sample images for demonstration
│   └── team/              # Team member photos
├── assets/
│   ├── documents/         # PDFs, reports, presentations
│   └── icons/             # SVG icons and graphics
└── README.md              # Project documentation
```

## Page Sections

### 1. **Hero Section**
- Eye-catching headline
- Brief tagline about AI image detection
- Call-to-action button (scroll to demo or learn more)
- Background: gradient or image related to AI/ML

### 2. **Problem Statement**
- Why detecting AI images matters
- Current challenges in the digital landscape
- Statistics or facts about AI-generated content

### 3. **Our Solution**
- Overview of your ML approach
- Key features of your detection model
- Technology stack used
- Model architecture (simplified for general audience)

### 4. **How It Works**
- Step-by-step process visualization
- Input → Processing → Detection → Results
- Visual flowchart or infographic

### 5. **Demo/Results Section**
- Sample images with detection results
- Accuracy metrics
- Comparison: Real vs AI-generated images
- Optional: Interactive demo (if you have a deployed model)

### 6. **Technical Deep Dive** (Optional)
- Dataset information
- Training process
- Model performance metrics
- Challenges overcome

### 7. **Meet the Team**
- Team member cards with photos
- Names, roles, and brief bios
- Contact links (LinkedIn, GitHub, etc.)

### 8. **Resources**
- Link to GitHub repository
- Documentation/Report download
- Presentation slides
- Research references

### 9. **Footer**
- Copyright information
- Module/Course attribution
- Social links
- Contact information

## Design Recommendations

### Color Scheme
- **Primary**: Deep blue or purple (tech/AI feel)
- **Secondary**: Bright accent (cyan, green, or orange)
- **Background**: White/light gray with dark sections for contrast
- **Text**: Dark gray on light, white on dark

### Typography
- **Headings**: Modern sans-serif (Poppins, Montserrat, Inter)
- **Body**: Readable sans-serif (Open Sans, Roboto, System UI)
- **Code/Technical**: Monospace (Fira Code, JetBrains Mono)

### Key Features
- Smooth scrolling navigation
- Scroll-triggered animations
- Desktop-optimized layout
- Fast loading times
- Accessible (WCAG compliant)

## Technology Stack

### Frontend
- HTML5
- CSS3 (with Flexbox/Grid)
- Vanilla JavaScript (ES6+)
- Optional: Tailwind CSS or Bootstrap for rapid styling

### Optional Enhancements
- AOS (Animate On Scroll) library
- Chart.js for visualizing metrics
- Particles.js for background effects
